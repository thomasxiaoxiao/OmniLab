# Two-minute scientific discovery demo

1. Open **Discovery overview** and select a verified Omnigent run. Show the
   hypothesis and exact source passage in the seed and proposals panel (20 seconds).
2. Show the planner's two sampling tests, expected learning, feasibility and cost;
   identify the selected test and actual trials (20 seconds).
3. In **Agents & loops**, inspect real reader, critic, literature, planner,
   validator, reference evaluator and next-decision sessions. Distinguish the
   Python simulation tools from model sessions (30 seconds).
4. Open **Original → follow-up** for the baseline and treatment comparison, then
   **Final synthesis** for the measurement paragraph, uncertainty chart and paper
   concept map. Explain the result-driven next action (30 seconds).
5. Show elapsed time, simulation counts and hashed artifacts. State that no
   comparable human baseline or global scientific novelty has been established.
   Explain the next experiment and remaining validation (20 seconds).

Use `research run --config examples/percolation/discovery.json` for a new live run.
A replay demonstrates recorded results; it does not itself execute live agents.
Older `codex-full-paper` evidence remains available, but predates structured test
comparisons and next-decision artifacts.
